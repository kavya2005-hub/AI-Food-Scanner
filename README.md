# 🍽️ AI Food Scanner

An AI-powered web application that analyzes food images to identify dishes, estimate nutritional values, and provide health insights. The application helps users make informed dietary choices using Artificial Intelligence.

---

## 🚀 Features

- 📸 Upload food images
- 🤖 AI-based food recognition
- 🥗 Detect food items from images
- 🔥 Estimate calories
- 🍎 Display nutritional information
- 💪 Health recommendations
- ⚡ Fast AI-powered analysis
- 🌐 Responsive user interface
- 📱 Works on desktop and mobile

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/AI-Food-Scanner.git
```

### Navigate

```bash
cd AI-Food-Scanner
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

Windows

```bash
venv\Scripts\activate
```

Linux / macOS

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

Open your browser:

```text
http://localhost:5000
```

# 📸 How It Works

1. Upload a food image.
2. AI analyzes the image.
3. Detects the food item.
4. Estimates calories.
5. Displays nutritional values.
6. Provides health suggestions.
